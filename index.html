Reasonable questions

We asked Jean. She declined to comment, so these answers are ours.

Is this actually a cat website?

Mostly. It is also the landing page for PEER. The cat records are sincere; the app download is clearly identified before it starts.

What will the button download?

The PEER Android APK from the project’s GitHub Releases page. A confirmation window shows the source first.

Why might Android show a warning?

Android may request permission to install an app obtained outside Google Play. Review the prompt and only continue if you trust the source.

Does PEER provide movies or TV?

No. It is a discovery and playback client. Availability depends on services, playlists, sources and add-ons configured by the user.
